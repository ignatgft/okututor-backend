# Okututor Backend Mockup

This is a Spring Boot backend scaffold that matches the current frontend API contract.

## Run

```bash
cd backend
mvn spring-boot:run
```

## Default demo accounts

- `teacher@okututor.dev` / `Password123!`
- `student@okututor.dev` / `Password123!`

## Local env

Copy `.env.example` to `.env` in the `backend/` folder or export the same variables in your shell.
